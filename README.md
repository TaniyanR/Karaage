# Karaage

WordPressの過去記事をランダムに選出し、重複期間・記事の古さ・カテゴリー・更新間隔を指定してRSS配信する軽量プラグインです。

## 主な機能

- 公開済みの通常投稿からランダムに記事を選出
- 一定期間、同じ記事を再利用しない
- 重複防止期間を選択可能
  - 1日
  - 7日
  - 30日
  - 60日
  - 180日
- 対象記事の古さを選択可能
  - 制限なし
  - 1日以上前
  - 7日以上前
  - 30日以上前
  - 60日以上前
  - 90日以上前
  - 180日以上前
  - 365日以上前
- 対象カテゴリーを複数選択可能
- カテゴリー未選択時は全カテゴリーが対象
- RSS更新間隔を選択可能
  - 10分
  - 30分
  - 60分
  - 3時間
  - 6時間
- WP-Cronで自動更新
- 管理画面から手動更新可能
- 専用RSS URLを自動生成

## RSS URL

```text
https://example.com/feed/karaage/
```

## RSSの記事数

WordPress本体の次の設定を利用します。

```text
設定 → 表示設定 → RSS/Atom フィードで表示する最新の投稿数
```

## インストール

1. このリポジトリをダウンロードします。
2. `karaage.php` を含む `Karaage` フォルダを `/wp-content/plugins/` に配置します。
3. WordPress管理画面の「プラグイン」から `Karaage` を有効化します。
4. 「設定 → Karaage」で各項目を設定します。

## 動作仕様

### ランダム選出

条件に一致する公開済み記事からランダムに選出します。

### 重複防止

一度RSSに選ばれた記事は、設定した重複防止期間中は候補から除外されます。
候補記事が不足している場合でも、重複防止ルールを破って再利用せず、取得できた件数だけRSSに出力します。

### 対象記事の古さ

たとえば「30日以上前」を指定した場合、公開から30日以上経過した記事だけが候補になります。

### カテゴリー

複数カテゴリーを指定できます。複数指定した場合は、そのいずれかに属する記事が候補になります。
何も選択しない場合は全カテゴリーが対象です。

### 更新間隔

WP-CronでRSSを定期的に再生成します。
WordPressのWP-Cronはサイトへのアクセスを契機に実行されるため、アクセスが少ないサイトでは設定時間より遅れて実行される場合があります。

## 管理画面

WordPress管理画面の次の場所から設定できます。

```text
設定 → Karaage
```

設定画面では以下を確認・変更できます。

- 同じ記事を再利用しない期間
- 対象記事の古さ
- 対象カテゴリー
- RSS更新間隔
- RSS URL
- RSSの記事数
- 最終生成日時
- 今すぐRSSを更新
